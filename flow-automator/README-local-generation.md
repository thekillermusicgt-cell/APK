# SRTSync local image generation

Esta versión incluye una sección de generación local por bloques para ComfyUI.

## Requisitos

- ComfyUI ejecutándose en `http://127.0.0.1:8188`
- Un modelo compatible cargado en ComfyUI (por ejemplo `model.safetensors`)
- Una GPU con memoria suficiente para la resolución elegida

## Uso

1. Abre ComfyUI y espera a que esté levantado.
2. Abre `index.html` en tu navegador.
3. Pega los prompts en la sección de **Generación local por bloques**.
4. Ajusta:
   - `Bloque` (por ejemplo 4)
   - `Ancho` y `Alto` (768x432 para YouTube)
   - `Steps`, `CFG` y `Pausa`
5. Pulsa **Generar por bloques**.
6. La app enviará los prompts en bloques y no saturará tu GPU.

## Recomendación para vídeo de YouTube

- Resolución inicial: 768x432
- Amplía después con Upscayl o RealESRGAN a 1920x1080
- Entra en modo de generación por bloques para evitar picos de memoria

La app no fuerza paralelismo: genera una imagen y espera antes de pasar a la siguiente.

## Nota

Si el modelo no se llama `model.safetensors`, cambia el nombre en el campo del formulario antes de empezar.
